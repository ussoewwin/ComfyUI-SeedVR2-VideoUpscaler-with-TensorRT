# DisTorch2 DiT 加载器节点 & Phase 2 显存控制 — v1.6.0

---

## 1. 概述

v1.6.0 新增一个基于 **DisTorch2** 的 DiT 加载器节点，可将整个量化（INT8 / NVFP4）DiT 常驻于系统内存，并在去噪过程中按需流式传输到计算设备；同时新增两个 Phase 2 显存开关（`norm_bf16`、`emb_repeat_nocache`），并对 INT8 量化路径做了加固（杜绝隐式 fp16 展开）。另对模型注册表做了精简（移除 fp8 条目）。

> **许可说明：** `src/distorch2/` 下的 DisTorch2 后端是
> [ComfyUI-MultiGPU](https://github.com/pollockjj/ComfyUI-MultiGPU)（pollockjj，**GPL-3.0**）的逐字副本，
> 本仓库其余部分为 **Apache 2.0**。详见 README 的 Credits/License 小节。

---

## 2. 新节点 — `SeedVR2 (Down)Load DiT Model with Distorch2`

- **node_id：** `SeedVR2LoadDiTModelDisTorch2`
- **display_name：** `SeedVR2 (Down)Load DiT Model with Distorch2`
- **输出：** 与标准加载器相同的 `SEEDVR2_DIT` 配置字典，另加一个 `distorch2` 块，因此可与 `SeedVR2 Video Upscaler` 完全一致地连接。

### 作用

将整个打包后的 DiT 常驻于 *donor* 设备（通常为 `cpu` = 系统内存），并在 DiT 前向过程中逐块将权重流式传输到计算设备，使用上游 DisTorch2 放置后端。这使得大型量化 DiT 可以在空闲显存远小于模型体积的 GPU 上运行。

### 输入参数

| 输入 | 类型 | 默认 | 用途 |
| --- | --- | --- | --- |
| `model` | DiT 检查点 | `seedvr2_7b_int8_convrot.safetensors` | DiT 模型（INT8 / NVFP4 / FP16）。 |
| `device` | 设备 | 首个设备 | DiT 推理的计算设备。 |
| `attention_mode` | 组合 | `sdpa` | `sdpa` / `flash_attn_2` / `flash_attn_3` / `sageattn_2` / `sageattn_3` / `spargeattn`。 |
| `sparge_topk` | 字符串 | `0.5` | SpargeAttn 的 KV 块保留比例。 |
| `distorch2_enabled` | 布尔 | `True` | 启用 DisTorch2 放置；关闭时行为等同标准加载器。 |
| `virtual_vram_gb` | 浮点 | `4.0` | 计算设备上为流式传输预留的虚拟显存预算（`0` = 整个模型保留在 donor）。 |
| `donor_device` | 组合 | `cpu` | 物理承载打包 DiT 权重的设备。 |
| `expert_mode_allocations` | 字符串 | `""` | 高级逐块设备分配字符串，如 `"cpu,cpu,cuda:0"`。 |
| `eject_models` | 布尔 | `True` | 放置前卸载其他常驻模型以释放显存。 |
| `emb_repeat_nocache` | 布尔 | `False` | 禁用 Phase 2 的 emb_repeat 缓存（见第 4 节）。 |
| `norm_bf16` | 布尔 | `False` | Phase 2 的 bf16 norm 路径（见第 3 节）。 |

节点会在控制台报告最终放置结果（`[MultiGPU DisTorch V2] ... Final Allocation String` 及逐设备的层分布表）。

### 分配字符串桥接层（`src/core/distorch2_placement.py`）

节点生成上游格式的分配字符串
`"<expert_mode_allocations>#<compute_device>;<virtual_vram_gb>;<donor_device>"`。桥接层
（`apply_distorch2_placement`）将 SeedVR2 DiT 接入所复制的后端：

- `FakePatcherAdapter` — 将 SeedVR2 DiT 呈现给 `analyze_safetensor_loading`。
- `build_packed_allocation_string` / `_parse_vram_string` — 以**打包后**的权重体积重新计算分配
  （上游按逻辑体积计算会把 CPU 分到 0）。
- `wrap_blocks_with_cache_release` — 在未启用 BlockSwap 时，逐块释放缓存（BlockSwap 时代的机制）。
- `ensure_backend_registered` — 幂等地注册打过补丁的 safetensor ModelPatcher。

放置在 `materialize_model` 中**先于** BlockSwap / compile 接线应用。

## 3. `norm_bf16` — Phase 2 的 RMS/QK norm 精度开关

DiT 的 RMS/QK norm（`CustomRMSNorm`）在每个 block 中被多次调用。在 `torch.autocast(bf16)` 下，
原生路径会将中间结果提升为 **fp32**，从而分配全尺寸 fp32 激活并抬高 Phase 2 显存。

- **关闭（默认）：** 原生 fp32 路径 — 输出与上一版本逐位相同。
- **开启：** bf16 路径 — `torch.mean(input * input, dim=..., dtype=input.dtype)`，并将权重转换为输入
  dtype，使整个 RMS 保持在 bf16。

开关接线为 节点 → 配置字典 → 环境变量 `SEEDVR2_NORM_BF16`，在前向内部读取（与既有开关一致）。
对 **7B** 与 **3B** 的 `CustomRMSNorm` 均已应用。

实测质量（本仓库测试环境，RTX 5060 Ti）：逐像素 **PSNR 约 37–39 dB**（相对 fp32 路径，bf16 舍入），
即为显存与质量的刻意取舍。

---

## 4. `emb_repeat_nocache` — Phase 2 的 emb_repeat 缓存开关

- **关闭（默认）：** 保留 `emb_repeat` 缓存（原生行为）。
- **开启：** 每次使用时重新计算 `repeat_interleave`。`repeat_interleave` 是纯拷贝，输出**逐位相同**；
  它在 Phase 2 期间释放共享的常驻缓存。

接线为 节点 → 配置字典 → 环境变量 `SEEDVR2_EMB_REPEAT_NOCACHE`。

---

## 5. INT8 量化路径加固（杜绝隐式 fp16）

量化 DiT 权重在前向中必须保持打包（INT8 / uint8 存储）；当激活为 bf16 时，若干 comfy 路径可能
会静默将其 fp16 展开。本次针对 **仅 DiT**（不动 VAE）封堵这些路径：

- **`src/core/model_loader.py`：** DiT 的 `comfy_quant` ops dtype 取自 runner 的流水线计算 dtype（bf16），
  不再硬编码 `torch.float16`，因此非量化 DiT 参数不会被强制为 fp16，QuantizedTensor 的逻辑 dtype 也
  不会被标记为 fp16。
- **`src/optimization/int8_native_ops.py` / `nvfp4_native_ops.py`：** `_mark_dit_locked` 包装 DiT 的
  `ops.Linear`，使打包（int8/uint8）权重被标记 `_dit_quant_locked`，从而阻止 `comfy_kitchen` 在遇到
  未实现的 op 时静默 fp16 展开已锁定的权重。
- comfy 的 cast/dequant 路径（`cast_bias_weight`、`post_cast`、`forward_comfy_cast_weights`、
  `_load_quantized_module`）加装守卫，已锁定的 DiT 权重永不被反量化为 fp16。

## 6. 模型注册表与 CLI

- **移除 fp8 DiT 条目**（3B、7B、7B sharp）。剩余 DiT 条目为 FP16、INT8（ConvRot）与 NVFP4。
- **`DEFAULT_DIT`** 现为 `seedvr2_7b_int8_convrot.safetensors`。
- **CLI：** 新增 `--distorch2` 系列开关（`--distorch2`、`--distorch2_virtual_vram_gb`、
  `--distorch2_donor`、`--distorch2_allocation`）供无界面使用。
