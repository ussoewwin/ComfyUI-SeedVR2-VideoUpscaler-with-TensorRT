# SeedVR2 Video Upscaler — 版本发布说明 (v1.6.8)

## 概述

SeedVR2 Video Upscaler v1.6.8 从 DiT 加载器节点中移除了 **SpargeAttn-hswq（`spargeattn`）注意力后端**。在实机验证中，`spargeattn` 在高目标分辨率下会在放大输出的纵向接缝处产生条纹噪声，而其余全部注意力后端（`sdpa`、`flash_attn_2`、`flash_attn_3`、`sageattn_2`、`sageattn_3`）在同一工作流、同一输入、同一分辨率下均不受影响。因此本次将该后端整体撤回。

---

## 1. 移除 `spargeattn` 选项

### 现象与定位

在同一工作流（同一输入、同一分辨率、同一随机种子）下逐一实测各注意力后端：

| `attention_mode` | 结果 |
| --- | --- |
| `sdpa` | 正常 |
| `flash_attn_2` | 正常 |
| `flash_attn_3` | 正常 |
| `sageattn_2` | 正常 |
| `sageattn_3` | 正常 |
| **`spargeattn`** | **纵向接缝条纹噪声** |

由于 `sageattn_2`（SpargeAttn 所基于的 SageAttention2++ 内核）表现正常，可确认问题位于 `spargeattn` 特有的**两阶段块稀疏过滤（block-sparse topk）**层，而非其底层的 SageAttention2++ 量化内核。

### 变更内容

`spargeattn` 已从两个 DiT 加载器节点的 `attention_mode` 组合框中移除：

- `SeedVR2 (Down)Load DiT Model`
- `SeedVR2 (Down)Load DiT Model with Distorch2`

保留的注意力后端为 **`sdpa` / `flash_attn_2` / `flash_attn_3` / `sageattn_2` / `sageattn_3`**。

---

## 2. 移除 `sparge_topk` 控件

随 `spargeattn` 一同，两个加载器节点上的 **`sparge_topk`（KV 块保留比例）** 输入控件及内部的配置传递接线一并移除。其余后端不使用该参数。

---

## 3. 文档同步

- `README.md` / `zhmd/README.md`：DiT 加载器参数说明同步更新，仅保留 `attention_mode`。
- `md/changelog.md` / `zhmd/changelogzh.md`：新增 v1.6.8 条目。

---

## 4. 变更文件与影响范围

- `src/interfaces/dit_model_loader.py`：从 `attention_mode` 选项中移除 `spargeattn`；移除 `sparge_topk` 控件、提示文案及其配置输出。
- `src/interfaces/dit_model_loader_distorch.py`：同上的对应改动。
- `src/interfaces/video_upscaler.py`：移除 `sparge_topk` 的接收与传递。
