# SeedVR2 Video Upscaler — 版本发布说明 (v1.6.6)

## 概述

SeedVR2 Video Upscaler v1.6.6 正式完成了对 **ConvRot W4A8（非对称 4-bit 权重 + 8-bit 激活量化）DiT 模型** 的全链路原生支持。涵盖 3B、7B、7B Sharp 全规格模型注册、自动下载、本地文件探索、UI 下拉菜单防误下载规范化以及后向兼容别名解析。同时，本版本明确规定了 W4A8 量化模型的兼容范围：W4A8 仅支持标准 DiT 加载器（`SeedVR2 (Down)Load DiT Model`），不支持 DisTorch2 加载器。

---

## 1. 3B / 7B / 7B Sharp ConvRot W4A8 DiT 模型原生全链路支持

### 支持的模型清单与 Hugging Face 权重资产
所有 W4A8 模型权重均托管于官方仓库 [`ussoewwin/SeedVR2-ConvRot-INT8-and-w4a8`](https://huggingface.co/ussoewwin/SeedVR2-ConvRot-INT8-and-w4a8)：
- **`seedvr2_3b_convrot_w4a8.safetensors`**：3B 非对称 W4A8 基础超分辨率模型。
- **`seedvr2_7b_convrot_w4a8.safetensors`**：7B 非对称 W4A8 基础超分辨率模型。
- **`seedvr2_7b_sharp_convrot_w4a8.safetensors`**：7B Sharp 非对称 W4A8 锐化超分辨率模型。

### 核心特性
- **极致显存节省**：W4A8 模型在保持高画质重建能力的同时，将 DiT 权重显存压缩至 4-bit，大幅降低去噪阶段（Phase 2）的显存占用，使 16GB / 12GB 显卡用户能够轻松运行 7B 规格的视频超分辨率任务。
- **完全对齐 ConvRot 旋转坐标系**：基于 ConvRot 优化算法，有效消除量化带来的激活离群值（outliers），输出质量与 FP16 基准高度吻合。

## 2. UI 下拉列表规范化与自动下载误触发根治

### 历史问题与排查
此前在 `src/utils/model_registry.py` 中，曾临时同时登记了非 convrot 命名（`seedvr2_*_w4a8.safetensors`）与 convrot 规范命名（`seedvr2_*_convrot_w4a8.safetensors`）。由于非 convrot 命名排在前面：
1. ComfyUI 节点界面生成的下拉选择列表中默认展示了非 convrot 名称。
2. 即使用户本地已经放置了规范命名的 `seedvr2_*_convrot_w4a8.safetensors` 权重文件，节点由于名称完全不匹配而无法命中本地缓存。
3. 导致工作流在执行时意外触发远端 Hugging Face 自动下载，严重浪费网络带宽与磁盘空间。

### 技术修复方案
1. **下拉列表规范化**：从 `MODEL_REGISTRY` 注册表中彻底剔除非 convrot 别名键，UI 下拉菜单严格只展示唯一的规范名称：`seedvr2_3b_convrot_w4a8.safetensors`、`seedvr2_7b_convrot_w4a8.safetensors`、`seedvr2_7b_sharp_convrot_w4a8.safetensors`。
2. **全自动别名解析与双向兼容（`MODEL_ALIASES`）**：
   - 在 `model_registry.py` 中建立全局别名映射表：
     ```python
     MODEL_ALIASES = {
         "seedvr2_3b_w4a8.safetensors": "seedvr2_3b_convrot_w4a8.safetensors",
         "seedvr2_7b_w4a8.safetensors": "seedvr2_7b_convrot_w4a8.safetensors",
         "seedvr2_7b_sharp_w4a8.safetensors": "seedvr2_7b_sharp_convrot_w4a8.safetensors",
     }
     ```
   - 在 `get_model_info()`、`get_model_repo()`、`find_model_file()` 以及 `download_weight()` 的入口处全链路引入别名动态解析。
   - 无论旧工作流传入的是非 convrot 名称还是规范名称，系统均能在本地探测并命中对应的 `*_convrot_w4a8.safetensors` 实体文件，绝不发生误下载。

---

## 3. DisTorch2 兼容范围限制明确

- **支持架构**：W4A8 模型**仅支持**通过标准 DiT 加载节点 **`SeedVR2 (Down)Load DiT Model`** 加载运行（可结合 BlockSwap 功能进一步缩减显存）。
- **DisTorch2 不支持 W4A8**：DisTorch2 加载节点（`SeedVR2 (Down)Load DiT Model with Distorch2`）**不支持** W4A8 模型。
- **技术原因**：DisTorch2 后端（基于 ComfyUI-MultiGPU）依赖逐层将权重张量在 CPU 内存与 GPU 显存之间流式传输，并在 PyTorch 层进行标准的线性投影调度；非对称 W4A8 采用特定的 4-bit 打包与解包算子，与 DisTorch2 的底层动态卸载与分块张量流式调度机制不兼容。因此对于 W4A8 模型，请始终使用标准 DiT 加载器。

## 4. 变更文件与影响范围

- `src/utils/model_registry.py`：清理重复键，规范 W4A8 注册名，增加 `MODEL_ALIASES`、`resolve_model_alias` 及 `get_model_info`。
- `src/utils/constants.py`：在 `find_model_file()` 中集成别名解析，确保本地文件发现精准命中。
- `src/utils/downloads.py`：在 `download_weight()` 中集成别名解析，彻底根除已有文件时的重复下载。
- `md/changelog.md` & `zhmd/changelogzh.md`：中英文更新日志同步更新。
