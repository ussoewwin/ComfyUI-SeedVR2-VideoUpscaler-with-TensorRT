## 第一部分：仅限加载器触发的模型自动下载（下载策略修正）

### 1. 修复前的问题与失效模式

#### 1.1 安装/更新时强制下载模型
- **问题**：`install.py` 在每次安装/更新时都会执行默认模型预下载步骤（经由 `scripts/download_models.py`），无条件拉取 `seedvr2_ema_3b_fp8_e4m3fn.safetensors` 与 `ema_vae_fp16.safetensors`。
- **现象**：不需要、不使用这些文件的用户，每次更新都会被重新下载——唯一规避方式是把文件一直留在硬盘上，白白占用磁盘与带宽（[#2](https://github.com/ussoewwin/ComfyUI-SeedVR2-VideoUpscaler-with-TensorRT/issues/2)）。

#### 1.2 TensorRT VAE 引擎构建时附带拉取默认 DiT
- **问题**：当加载器所选 VAE 文件缺失时，`src/interfaces/trt_vae_model_loader.py` 调用 `download_weight(DEFAULT_DIT, model, ...)`，连带拉取默认 3B FP8 DiT。
- **现象**：构建 TensorRT VAE 引擎时可能下载未请求的默认 DiT 模型。

### 2. 新的下载策略（已修正）

> **仅当在加载器节点中选择了模型且文件缺失时，才会自动下载。**

除此之外不存在任何其他自动下载：

| 触发场景 | 下载行为 |
| :--- | :--- |
| 安装 / 更新 | **不下载** |
| 运行放大器节点 | 仅下载节点所选 DiT / VAE（缺失时） |
| TensorRT VAE 引擎构建 | 仅下载加载器所选 VAE（缺失时） |
| CLI（`inference_cli.py`） | 仅下载 CLI 参数所选模型 |

### 3. 修复与修改的文件

| 文件 | 状态 | 变更 |
| :--- | :--- | :--- |
| `install.py` | 修改 | 移除 `download_default_models()` 及其第 4 步调用；安装/更新不再预下载 |
| `scripts/install.ps1` | 修改 | 移除强制默认模型下载块 |
| `src/interfaces/trt_vae_model_loader.py` | 修改 | 仅下载加载器所选 VAE（绝不下载默认 DiT） |
| `src/utils/downloads.py` | 修改 | `download_weight()` 的 `dit_model` / `vae_model` 改为可选；仅处理显式传入的名称（`None` 跳过） |

### 4. 关键代码变更

```python
# install.py — step 4 policy change
# 4. Default models: intentionally NOT pre-downloaded.
#    Downloads happen only when a model is selected in a loader node and is missing.
```

```python
# src/interfaces/trt_vae_model_loader.py — selected VAE only
if not (model_dir / model).exists():
    print(f"[SeedVR2 TensorRT] Downloading {model} to {model_dir}...")
    # Download only the model selected in the loader (never the default DiT).
    download_weight(vae_model=model, model_dir=str(model_dir))
```

```python
# src/utils/downloads.py — optional slots
def download_weight(dit_model: Optional[str] = None, vae_model: Optional[str] = None, model_dir: Optional[str] = None, debug=None) -> bool:
    ...
    files_to_download = [
        (name, MODEL_REGISTRY.get(name))
        for name in (dit_model, vae_model)
        if name
    ]
```
