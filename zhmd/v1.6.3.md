# v1.6.3 — `triton-windows` 动态解析与解除版本固定

本版本移除了 Windows / CUDA 13.2 依赖清单中对 `triton-windows` 的硬编码版本绑定（`triton-windows==3.5.1.post24`），将 Triton 运行时依赖全面升级为动态解析最新版本。

通过解除版本锁定，环境配置与安装流水线能够自动从 PyPI 获取并安装最新版本的 `triton-windows` 构建，自适应更新的 PyTorch 运行时与 CUDA 环境，无需手动维护或重新固定版本号。

---

## 1. 核心变更概览

| 变更项 | v1.6.2 及以前 | v1.6.3 |
|---|---|---|
| **requirements-windows-cu132.txt** | 硬编码固定为 `triton-windows==3.5.1.post24` | **`triton-windows`**（自动解析最新版） |
| **安装与运行行为** | 仅安装或锁定特定的旧构建 | 允许 `pip` 自动解析并安装当前 Python 与 CUDA 对应的最新构建 |
| **文档与更新日志** | 引用旧版本固定说明 | 中英文 CHANGELOG 均同步为最新版动态解析说明 |

---

## 2. 变更详情

### 1. Windows CUDA 13.2 依赖清单 (`requirements-windows-cu132.txt`)
- 将 `triton-windows==3.5.1.post24` 更改为未锁定的 `triton-windows`。
- 保证与 `install.py` 中的未锁定安装逻辑（`ensure_package("triton", "triton-windows" if sys.platform.startswith("win") else "triton", no_deps=True)`）保持 100% 架构一致性。

### 2. 更新日志同步
- 同步更新 [md/changelog.md](../md/changelog.md) 与 [zhmd/changelogzh.md](changelogzh.md)，提供中英文双向语言一致链接。
